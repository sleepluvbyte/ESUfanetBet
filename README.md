# ESUfanetBet_bot — Telegram-бот турнира по CS 2

Бот для внутрикорпоративного турнира по CS 2 между филиалами:
- регистрация участников (ФИО + филиал) один раз, привязка по Telegram ID;
- прогнозы на исходы матчей (кто победит) прямо в боте;
- автоматические напоминания за 2 часа до матча;
- рейтинг участников по баллам в конце дня;
- выгрузка итоговой таблицы (ФИО без дублей) в Google Sheets;
- жеребьёвка среди угадавших 70%+ матчей (призы на стриме).

## Настройка `.env`

| Переменная | Описание |
|---|---|
| `TELEGRAMM_TOKEN` | токен бота от @BotFather |
| `GS_SHEETS` | ID Google-таблицы |
| `BRANCHES` | филиалы через запятую (кнопки при регистрации) |
| `ADMIN_IDS` | Telegram ID админов через запятую (узнать у @userinfobot) |
| `TIMEZONE` | часовой пояс (напр. `Asia/Yekaterinburg`) |
| `RATING_TIME` | время ежедневного рейтинга `ЧЧ:ММ` |
| `REMINDER_MINUTES` | за сколько минут напоминать о матче (по умолчанию 120) |
| `RATING_CHAT_ID` | ID канала/группы для публикации рейтинга (пусто = рассылка в личку) |
| `DRAW_THRESHOLD` | порог для розыгрыша (0.7 = 70%) |
| `PROXY_URL` | прокси для Telegram (пусто = без прокси). Напр. `socks5://user:pass@host:1080` |
| `SHEET_SCORES` | имя общей матрицы «участники × матчи» (по умолчанию `Баллы`); листы этапов называются по этапам |

Сервисный аккаунт `betufanet@ufanet-sheets-bot.iam.gserviceaccount.com` должен иметь доступ
к таблице (Поделиться → добавить этот email как редактора).

## Запуск

```powershell
# 1. Установить зависимости (при необходимости)
pip install -r requirements.txt

# 2. Создать/проверить листы в таблице
python setup_sheets.py

# 3. Запустить бота
python run.py
```

Или просто двойной клик по `start.bat`.

> Бот должен быть запущен постоянно, чтобы приходили напоминания и дневной рейтинг.
> Достаточно держать открытым окно `start.bat` либо оформить автозапуск (Планировщик заданий Windows).

## Листы Google Sheets

- **Матчи** — `ID | Этап | Регион | Дата | Время | Команда А | Команда Б | Филиал А | Филиал Б | Результат | Напоминание`
- **Участники** — `TG ID | ФИО | Регион | Username | Дата регистрации` (заполняется ботом)
- **Прогнозы** — `TG ID | Матч ID | Прогноз | Балл | Обновлено` (заполняется ботом)
- **Итоги** — создаётся командой `/export`: все участники (ФИО без дублей), баллы,
  статистика по каждому этапу и флаг «В розыгрыше (70%+)».
- **Розыгрыш** — создаётся командой `/export`: только участники с порогом 70%+
  и готовыми порядковыми номерами. Розыгрыш проводит человек по этим номерам
  (например, рандомайзером на стриме).
- **Баллы** — общая матрица «участники × матчи». Строки — участники (ФИО без дублей),
  столбцы — матчи, последний столбец — сумма. В ячейке: `1` — прогноз верный,
  `0` — прогноз был, но неверный, `·` — прогноз сделан, матч ещё не сыгран,
  пусто — прогноза нет.
- **Отборочный / Полуфинал / Финал онлайн / Финал оффлайн** — такая же матрица,
  но только по матчам своего этапа, «Сумма» = баллы за этот этап. Участники
  включаются все (даже если в этапе ещё нет матчей), чтобы листы были готовы заранее.

Все матрицы (общая + по этапам) обновляются `/scoreboard`, `/export`, при сохранении
прогноза, при вводе результата, а также автоматически каждые 5 минут и вместе с
дневным рейтингом в 21:00. Этапная матрица учитывает только матчи своего этапа
(после ввода результата баллы пересчитываются сразу в обоих листах).

### Как вести матчи (важно!)

**Основной способ — через бота:** `/admin` → «➕ Новый матч» (или `/addmatch`).
Пошагово: этап → дата → время → Команда А → Команда Б → Филиал А → Филиал Б →
подтверждение. Матч записывается в лист **Матчи**, а всем зарегистрированным
участникам сразу уходит анонс с кнопкой «🔮 Сделать прогноз».

Результат тоже вводится через бота: `/admin` → «✅ Результат матча» (или `/result`) —
список нерешённых матчей → кнопки с победившей командой. После этого баллы
пересчитываются автоматически, обновляются и листы-матрицы («Баллы» и этапные).

Ручной ввод в листе **Матчи** тоже работает (запасной вариант). Колонка **Результат**
заполняется после матча одним из вариантов:
- имя победившей команды (`Team Spirit`), либо
- `А`/`A` (победила Команда А) или `Б`/`B` (победила Команда Б).

Как только в «Результат» что-то вписано, матч считается сыгранным: баллы начисляются,
прогнозы закрываются, матч попадает в рейтинг и итоги.

Этапы (`Этап`): `Отборочный`, `Полуфинал`, `Финал онлайн`, `Финал оффлайн`.

## Команды участников

- `/start` — регистрация (ФИО + филиал) и главное меню
- `/matches` — ближайшие матчи и прогнозы
- `/rating` — рейтинг по баллам
- `/me` — профиль, баллы и место
- `/id` — мой Telegram ID

## Админ-команды

`/admin` открывает кнопочную админ-панель. Там же команды работают и как `/...`.

- `/admin` — панель с кнопками (Новый матч, Результат, Баллы, Пересчитать, Итоги, Статистика, Рассылка)
- `/addmatch` — завести новый матч (пошаговый мастер) и разослать анонс
- `/result` — отметить победителя нерешённого матча (кнопками)
- `/scoreboard` — обновить лист-матрицу «Баллы» и листы каждого этапа
- `/stats` — статистика турнира
- `/test` — проверка настроек и ближайшего напоминания
- `/dryrun` — превью напоминания (только админу, без рассылки)
- `/ratingnow` — превью дневного рейтинга (только админу)
- `/refresh` — пересчитать баллы прогнозов
- `/export` — выгрузить листы «Итоги» и «Розыгрыш»
- `/broadcast` — рассылка всем участникам
- `/cancel` — отменить текущее действие (мастер, рассылку)

## Логика

- **Баллы:** 1 балл за каждого угаданного победителя.
- **Дубли ФИО:** в рейтинге и итогах участники группируются по нормализованному ФИО;
  если человек зарегистрировался несколько раз, матч всё равно учитывается один раз.
- **Порог розыгрыша:** доля угаданных от всех сыгранных матчей ≥ `DRAW_THRESHOLD` (70%).
- **Розыгрыш:** бот НЕ разыгрывает призы сам. Он выгружает лист «Розыгрыш» с
  порядковыми номерами и статистикой — человек проводит розыгрыш по этим данным
  (рандомайзером на стриме).

## Быстрая проверка перед турниром

```powershell
python seed_demo.py     # тестовые участники, матчи всех этапов, прогнозы
python run.py           # запустить бота и проверить команды
python clear_demo.py    # удалить тестовые данные перед реальным турниром
```

После `seed_demo.py` в боте можно проверить `/rating`, `/matches`, `/me`,
а админу — `/test`, `/dryrun`, `/refresh`, `/export`. Матч `DEMO09` начнётся
через ~90 минут — сработает тестовое напоминание.

## Развёртывание на VPS (рекомендуется)

Бот должен работать круглосуточно, поэтому его лучше держать на VPS.
В локальной/корпоративной сети Уфанет Telegram часто недоступен — на VPS он работает.

### Вариант 1 — деплой прямо с Windows (проще всего)

Установи `paramiko` и запусти скрипт (пароль передаётся через переменную, в файл не пишется):

```powershell
pip install paramiko
$env:VPS_HOST="185.133.174.73"   # можно не указывать — есть по умолчанию
$env:VPS_PASS="<пароль root>"
python deploy\deploy_from_windows.py            # полная установка
python deploy\deploy_from_windows.py update     # обновить код и перезапустить
```

### Вариант 2 — вручную на сервере

```bash
# залить проект (WinSCP/scp) в /opt/esufanetbot, затем:
cd /opt/esufanetbot
sed -i 's/\r$//' deploy/*.sh      # убрать CRLF от Windows
bash deploy/setup.sh              # установит Python, venv, зависимости и сервис
```

### Полезные команды на сервере

```bash
systemctl status esufanetbot      # состояние
systemctl restart esufanetbot     # перезапуск
journalctl -u esufanetbot -f      # живые логи
```

Файлы бота: `/opt/esufanetbot`, сервис: `esufanetbot` (systemd, автозапуск включён).
Часовой пояс матчей берётся из `TIMEZONE` в `.env`, поэтому сервер может быть в UTC.

> После установки смени пароль root (`passwd`) и/или добавь SSH-ключ — пароль,
> присланный в чат, лучше считать скомпрометированным.

## Если бот не подключается к Telegram

Если при `python run.py` ошибка вида `TelegramNetworkError` / `WinError 121`
/ `Cannot connect to host api.telegram.org`, значит сеть блокирует Telegram
(частая ситуация у российских провайдеров и корпоративных сетей). Проверить:

```powershell
python check_net.py
```

Если Telegram помечен как НЕДОСТУПНО, а Google — доступен, используй один из вариантов:

1. **Прокси** — пропиши в `.env`:
   ```
   PROXY_URL=socks5://user:pass@host:1080
   ```
   и установи зависимость: `pip install aiohttp-socks`.
   (можно и HTTP-прокси: `PROXY_URL=http://user:pass@host:8080`.)
2. **VPN** — запускать бота при включённом VPN.
3. **Сервер/VPS** — см. раздел выше (рекомендуемый вариант для турнира).
